# 02 星形装药（近中性）

## 目的
演示**星形药柱**（star，6 星角）的燃面"先增后减"特性，以及由此得到的
近中性推力曲线；同时展示固定几何算例的裕度评估方式。

## 输入
- 药型：星形（`star`），6 星角，内径 0.04 m，星角直径 0.12 m，半角 30°，
  外径 0.16 m，长 0.5 m，端面抑制。
- 推进剂：`ap_htpb_80`。
- 名义指标：推力 8000 N，工作时间 4 s，压强上限 9 MPa，外径 0.16 m。

## 运行
```bash
PYTHONPATH=src python examples/run_case.py examples/projects/02_star_neutral
```

## 预期结果（实测）
- 平均推力 ≈ 15075 N，工作时间 ≈ 1.56 s。
- 校核：5/8 项通过。

## 说明
所给星形几何燃面偏大，实际推力高于名义指标，故对指标的三项检查不通过。
`06_synthesis_star` 是由指标**合成**星形药柱的对照算例。
