# 08 · 逆向路径 A、可辨识性与不确定性

本例把三条**逆向**入口和**批量研究**串成一条可复现的流程，全部基于
`examples/run_case.py` 之外的脚本 `study.py`（见下），不需要人工干预。

## 内容

1. **逆向路径 A（几何）**：由 6 槽药型的二维端口轮廓（合成后加 0.1 mm 噪声）
   反推 `n_slots / inner_diameter / slot_width / slot_depth`。
2. **可辨识性**：对星形药型构造 `A_b(e)` 灵敏度矩阵，报告条件数与 VIF。
3. **参数扫描**：固定管形药型，扫描压强上限。
4. **蒙特卡洛**：扰动密度与燃速系数，给出推力/总冲的分布（固定种子）。

## 运行

```bash
PYTHONPATH=src python examples/projects/08_inverse_identifiability/study.py
```

## 预期结果（本机实测）

- 路径 A（含 0.1 mm 轮廓噪声）：目标函数 ~2.6e-4，瓣数恢复为 6，连续参数相对
  误差 < 1%（无噪声时目标函数降至 ~1e-21，参数逐位恢复）。
- 可辨识性：星形 `inner_diameter` 与 `length` 判为 `confounded`（VIF>10），
  因为两者对 `A_b` 的作用近似成比例——这正是"燃面数据难以唯一确定孔径与
  长度"的教科书结论；整数 `n_points` 标为 `frozen`。
- 扫描：峰值压强随压强上限单调上升。
- 蒙特卡洛：同一种子两次运行结果逐位一致。

> 这些数字由代码现场计算，不在文档中硬编码为"结论"；README 只说明应观察到
> 的**定性**趋势与量级。
