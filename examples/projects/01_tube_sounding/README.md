# 01 管形装药（固定几何）

## 目的
最简单的**固定几何**算例：给定中央圆孔的管形药柱，评估其燃面演化、
内弹道与性能，并观察校核链路如何报告"给定药型"相对名义指标的裕度。

## 输入
- 药型：管形（`tube`），内径 0.06 m，外径 0.16 m，长 0.5 m，端面抑制（内部燃烧）。
- 推进剂：`ap_htpb_80`（AP/HTPB 80/20，代表性数据）。
- 名义指标：推力 1500 N，工作时间 3 s，压强上限 7 MPa，外径 0.12 m。

## 运行
```bash
PYTHONPATH=src python examples/run_case.py examples/projects/01_tube_sounding
```

## 预期结果（实测）
- 平均推力 ≈ 6393 N，工作时间 ≈ 5.22 s，总冲 ≈ 3.34e4 N·s。
- 校核：5/8 项通过。

## 说明
该算例是**裕度评估**而非指标匹配：所给几何的燃面远大于 1500 N 所需，
因此推力/总冲/工作时间三项"对指标"检查不通过——这正是校核链路的提示。
管形内部燃烧为**渐进**（燃面随退移增大）。指标匹配见 `06/07` 与逆向设计。
