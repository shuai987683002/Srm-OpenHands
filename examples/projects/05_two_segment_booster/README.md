# 05 分段助推器（管形 + 星形）

## 目的
演示**多段药柱**：一个 `GrainGeometry` 由多个段组成，各段可选用不同的
药型族。本例由一段管形（渐进）与一段星形（近中性）串联，展示分段装药的
燃面叠加与总性能计算。

## 输入
- 段 1：管形（`tube`），内径 0.05 m，外径 0.16 m，长 0.3 m。
- 段 2：星形（`star`），6 星角，内径 0.04 m，星角直径 0.12 m，半角 30°，
  外径 0.16 m，长 0.3 m。
- 推进剂：`ap_htpb_75_al`。
- 名义指标：推力 30000 N，工作时间 6 s，压强上限 9 MPa，外径 0.3 m。

## 运行
```bash
PYTHONPATH=src python examples/run_case.py examples/projects/05_two_segment_booster
```

## 预期结果（实测）
- 平均推力 ≈ 4023 N，工作时间 ≈ 9.10 s。
- 校核：5/8 项通过。

## 说明
各段的燃面在同一退移量下分别计算后求和，是分段柱药的标准处理方式。
