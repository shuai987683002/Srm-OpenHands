# 03 车轮形装药（退减）

## 目的
演示**车轮形**（wagon_wheel，6 辐条）药柱的**退减**燃面特性：辐条先烧完，
之后燃烧退化为内孔，燃面随时间下降，推力曲线退减。

## 输入
- 药型：车轮形（`wagon_wheel`），6 辐条，内径 0.04 m，辐条宽 0.02 m，
  辐条长 0.05 m，外径 0.18 m，长 0.5 m，端面抑制。
- 推进剂：`ap_htpb_75_al`（含铝复合推进剂，代表性数据）。
- 名义指标：推力 20000 N，工作时间 2 s，压强上限 11 MPa，外径 0.2 m。

## 运行
```bash
PYTHONPATH=src python examples/run_case.py examples/projects/03_wagon_wheel_regressive
```

## 预期结果（实测）
- 平均推力 ≈ 17784 N，工作时间 ≈ 1.16 s。
- 校核：5/8 项通过（名义指标未刻意与几何对齐，见 `01` 的说明）。

## 说明
车轮形由"轮毂内孔 + 细径向通道 + 外圈圆形药腔"组成：外圈药腔是额外燃面，
先烧完，之后燃面退化为内孔，是典型的**退减**设计。三腔式药型（车轮/开槽/
翼柱）在几何上互不相同：车轮为圆形外腔、开槽为等宽直槽、翼柱为渐缩翼片。
