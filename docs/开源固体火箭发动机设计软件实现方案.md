# 开源固体火箭发动机设计软件（Srm-Open）实现方案

> 版本：v0.1（方案/架构阶段，未编码）
> 定位：科研教学 + 非商业工业研发的**开源**固体火箭发动机（Solid Rocket Motor, SRM）设计工具
> 编制视角：固体火箭发动机总体/装药/内弹道工程
> 本文性质：**设计方案**，不含任何工程实现结论；凡涉及具体数值、经验系数、材料参数处，均标注为"待数据填充"或"示例占位"，不给出未经验证的推测值。

---

## 0. 阅读须知与资料边界声明

本方案依据**公开、通用**的固体火箭推进原理（质量守恒/燃速定律/等熵喷管流动/燃面几何演化）与公开开源工具生态编制。为遵守"资料不足时明确假设、不推测结论"的要求，先做三点声明：

1. **理论层面**：所依据的物理模型为公开教科书级模型（内弹道零维/准一维平衡压强模型、Saint-Robert 燃速定律、等熵喷管流量公式等），属于公开知识，不涉及任何受控技术细节。
2. **数据层面**：真实推进剂配方、燃速系数、温度敏感系数、力学性能、壳体材料许用应力、喷管烧蚀率等**属于行业数据/敏感数据**，本方案一律以"数据字典/可插拔数据集"的方式预留接口，**不内置、不推测**任何真实数值。
3. **边界层面**：本软件为**设计计算与教学仿真**工具，输出为数值结果与三维几何，**不构成工程定型依据**，不覆盖点火、工艺、试验、安全性等工程环节。

## 1. 软件定位、适用边界与开源使用边界

### 1.1 软件定位

| 维度 | 定位 |
|---|---|
| 目标用户 | 高校教师/研究生（推进原理、内弹道教学）、开源火箭爱好者、非商业科研团队 |
| 核心能力 | 固体发动机**装药药型设计**（正向/逆向）+ **燃面演化** + **内弹道** + **性能核心分析** + **柱药主体计算** |
| 形态 | 跨平台桌面/本地服务应用：Python 计算内核 + Web/桌面 UI，支持脚本化（API/CLI）与交互式两种用法 |
| 输出 | 药型参数、三维几何（STEP/STL）、燃面-时间曲线、压强-时间曲线、推力-时间曲线、总冲/比冲等性能指标、校核报告 |
| 哲学 | "可复现、可扩展、可教学"：所有模型显式化、可替换，所有结果可溯源到输入与模型假设 |

**一句话定位**：一个面向教学与非商业研发的、开源的、从"指标↔药型↔燃面↔内弹道↔性能"双向贯通、并内置校核链路的固体火箭发动机装药与内弹道设计平台。

### 1.2 适用边界（做什么 / 不做什么）

**适用（In-Scope）**

- 单室、单级、**固体推进剂**发动机（含端面燃烧、内孔燃烧、内外同时燃烧等常见装药构型）。
- 药型族：圆柱形（端面/内孔）、管形、星形（多星角/锥星）、车轮形、开槽/翼柱形、球形/锥形孔、以及上述的**分段组合与前后段差异药型**（多段柱药拼接）。
- 零维平衡压强内弹道 + 准一维（可选）喷管流动；平衡/非平衡燃面演化。
- 恒定/分段燃速、压强指数、温度敏感性的参数化建模（数值由用户输入）。
- 稳态性能核心分析：总冲、比冲、推力系数、面喉比、余药、装载分数、喉部/壳体压强峰值等。
- 逆向设计：从几何/燃面数据/弹道指标反推设计参数（详见 §5）。

**不适用（Out-of-Scope，明确排除）**

- 液体/固液混合/电推进发动机。
- 二维/三维两相流、湍流、侵蚀燃烧（erosive burning）的**高保真** CFD 求解（仅预留接口/可选经验修正，不作为核心）。
- 结构强度详细有限元、热防护烧蚀详细计算、喷管型面详细设计（仅做工程级简化校核，详见 §6.6）。
- 点火瞬变、点火器设计、飞行力学、控制系统。
- 生产工艺、装药工艺、贮存老化、安全性/危险品评估。
- 任何面向实际武器化、批产定型的用途。

## 3. 模块划分（职责 + 输入输出）

软件采用**分层 + 插件化**架构，共 9 个功能域：

```
┌───────────────────────────────────────────────────────────────┐
│  UI/API 层    交互界面 · CLI · 脚本API · 报告导出               │
├───────────────────────────────────────────────────────────────┤
│  设计编排层   正向设计编排 · 逆向设计编排 · 校核链路编排          │
├───────────────────────────────────────────────────────────────┤
│  领域模型层   推进剂 · 喷管 · 药型 · 内弹道 · 性能 · 柱药主体      │
├───────────────────────────────────────────────────────────────┤
│  计算内核层   燃速模型 · 燃面演化 · 内弹道求解 · 性能分析 · 优化器  │
├───────────────────────────────────────────────────────────────┤
│  几何/网格层  参数化几何 · 网格/离散 · 导出(STEP/STL)            │
├───────────────────────────────────────────────────────────────┤
│  数据层       数据字典 · 数据集 · 项目文件 · 结果缓存 · SBOM      │
└───────────────────────────────────────────────────────────────┘
```

### 3.1 M1 指标解析与校验模块（Requirements & Validation）

- **职责**：解析初始总体指标，做量纲/守恒/区间一致性校验，识别"欠定/过定"。
- **输入**：推力 F、工作时间 t_b、装药量 m_p 或总冲 I_t、比冲 I_sp、外径 D、长径比 L/D、可选喷管喉径等（部分即可）。
- **输出**：`RequirementSet`（标准化、含冗余关系与冲突标记）；补全建议（缺失量由关系式推导：I_t = m_p·I_sp 等）。
- **关键点**：给出"自由度分析"——指标数量与药型自由度数是否匹配，为正向/逆向选择提供依据。

### 3.2 M2 推进剂模型模块（Propellant Model）

- **职责**：管理推进剂热化学/燃烧/密度属性；提供燃速模型与 c*、γ、分子量、燃烧温度接口。
- **输入**：推进剂数据集（用户选择/导入）；工作压强范围。
- **输出**：`PropellantModel`（r(p,T) 燃速函数、c*(p)、γ(p)、ρ_p、T_c 等），并给出**数据来源与不确定度**标注。
- **接口**：`burn_rate(p, T) -> r`；`c_star(p) -> c*`；`gamma(p) -> γ`。
- **说明**：热化学数据可选由 RocketCEA/Cantera 计算（基于用户提供的**元素级**配方），或由用户直接给 c*/γ；**不内置配方**。

### 3.3 M3 喷管模型模块（Nozzle Model）

- **职责**：喉部/出口流动、推力系数、膨胀比、喉部烧蚀的工程级建模。
- **输入**：喉径 A_t、膨胀比 ε、收敛/扩张半角、喷管效率 η、可选喉部烧蚀率（用户输入）。
- **输出**：`NozzleModel`（C_F(p,ε,γ)、ṁ(p)、A_t(t) 含烧蚀选项）。
- **接口**：`thrust_coefficient(pc, pe) -> C_F`；`mass_flow(pc) -> ṁ`。

### 3.4 M4 药型参数化与几何模块（Grain Geometry）

- **职责**：以**参数化**方式定义药型（族 + 参数向量）；生成二维轮廓与三维实体；导出。
- **输入**：药型族选择 + 参数向量 θ（星角数、星角半径、内径、外径、长度、切槽尺寸、锥度等）。
- **输出**：`GrainGeometry`（2D 轮廓 + 3D 实体 + 特征量：初始燃面 A_b0、肉厚 e、容积 V、余药几何）。
- **接口**：`build(θ) -> GrainGeometry`；`export(step/stl)`。
- **技术**：CadQuery（OpenCASCADE 内核）参数化建模。

### 3.5 M5 燃面演化引擎（Burnback Engine）

- **职责**：计算燃面 A_b 随燃烧距离/时间的变化（燃面演化），是正向/逆向的共同核心。
- **双通道设计（互校）**：
  - **通道 A：几何解析/半解析法**——针对标准族（管形/星形等）给出 A_b(e) 解析或级数解，快且精确。
  - **通道 B：Level-Set 法**——以符号距离函数 φ(x,t)=0 表示燃面，按法向速度 r 推进（∂φ/∂t + r|∇φ| = 0），支持任意复杂药型。
- **输入**：`GrainGeometry` + 燃速 r(p,T) + 离散设置（网格/步长）。
- **输出**：`BurnbackResult`（A_b(t)、A_b(e)、余药时刻、燃面三维快照序列）。
- **接口**：`evolve(geom, r) -> BurnbackResult`；支持 `method ∈ {analytic, levelset}`。

### 3.6 M6 内弹道求解模块（Internal Ballistics）

- **职责**：求解燃烧室压强-时间历史与流量平衡。
- **模型**：零维（集总参数）质量守恒：
  `V_c(t)·dρ_c/dt + ρ_c·dV_c/dt = ρ_p·A_b(t)·r(p) − ṁ_out(p)`
  教学默认取**平衡压强**简化：`ρ_p·A_b·a·p^n = p·A_t/c*`（即 `p = (ρ_p·c*·a·A_b/A_t)^(1/(1−n))`）；可选非平衡瞬变积分。
- **输入**：`BurnbackResult` + `PropellantModel` + `NozzleModel` + 初始自由容积。
- **输出**：`InternalBallisticsResult`（p_c(t)、ṁ(t)、p_c 峰值、面喉比 J(t)=A_b/A_t）。
- **接口**：`solve(burnback, prop, nozzle, V_free0) -> InternalBallisticsResult`。

### 3.7 M7 性能分析模块（Performance Analysis）

- **职责**：由 p_c(t)、A_b(t)、喷管参数计算性能指标与校核量。
- **输入**：内弹道结果 + 喷管 + 推进剂。
- **输出**：`PerformanceResult`（F(t)、I_t、I_sp、C_F、总冲/比冲、余药比、装载分数、质量比、峰值压强/推力、工作时间）。
- **公式**：`F(t)=C_F·A_t·p_c(t)`；`I_t=∫F dt`；`I_sp=I_t/(m_p·g_0)`。

### 3.8 M8 柱药主体计算模块（Cylindrical Grain Main-Body）

- **职责**：针对**柱形药柱主体**做专门计算（这是行业高频需求）。
- **内容**：主体几何（内/外径、长度、分段拼接）、初始燃面、肉厚 e、燃面演化（内外同时燃烧）、余药（sliver）计算、体积装载分数、长径比、以及**工程级**结构/应力简化校核（薄壁圆筒/厚壁圆筒/组合厚壁公式，材料许用值由用户输入）。
- **输入**：柱药几何参数 + 燃烧方式（内孔/端面/内外同时）+ 材料许用参数。
- **输出**：`GrainBodyResult`（主体燃面曲线、肉厚、余药量、装载分数、应力/安全裕度工程估算 + 假设标注）。

### 3.9 M9 正向/逆向设计编排 + 校核 + 优化模块

- **正向设计编排（Forward Design Orchestrator）**：M1→M4→M5→M6→M7→M8 串接，含"药型选型建议"（按长径比、工作压强、推力-时间形状需求选族）。
- **逆向设计编排（Inverse Design Orchestrator）**：三条路径（§5.2），调用 M5/M6 作"正演算子"，用优化器反演 θ。
- **优化器**：`pymoo`（多目标/遗传/CMA-ES 接口）+ 局部精修（scipy）。
- **校核模块（Verification）**：见 §6.6，输出残差与置信提示。
- **输出**：`DesignResult`（含设计向量、性能、校核报告、复现信息）。

## 4. 核心数据模型与数据流

### 4.1 核心数据模型（数据结构草案，pydantic/数据类）

```python
# 1) 指标集
RequirementSet:
    thrust_F, burn_time_tb, prop_mass_mp, total_impulse_It,
    specific_impulse_Isp, outer_diameter_D, length_ratio_LD,
    throat_diameter_dt, ...   # 允许部分缺失；含 consistency_flags

# 2) 推进剂
PropellantModel:
    id, name, source_note, uncertainty
    density_rho_p
    burn_rate: {law:"saint_robert", a, n, sigma_p_T, T_ref, a_range}
    c_star: {mode:"const|table|cea", value/table/cea_input}
    gamma: {mode, value/table}
    combustion_temp_Tc
    # 注：a, n, sigma_p, c*, gamma 均为用户提供，软件不内置

# 3) 喷管
NozzleModel:
    throat_area_At, exit_ratio_eps, half_angles,
    efficiency_eta, throat_erosion: {enabled, rate}
    cstar_eff, cf_eff

# 4) 药型几何
GrainGeometry:
    family: "cyl|tube|star|wheel|slotted|spherical|multi_segment"
    params: theta  (族相关参数向量)
    segments: [ {length, params, burn_mode} ]   # 多段柱药
    outline_2d, solid_3d
    features: {Ab0, web_thickness_e, volume_V, port_volume}

# 5) 燃面演化
BurnbackResult:
    method, settings
    t[], burn_distance_e[], Ab[], Ab_over_At[]
    snapshots: [3d_surface], sliver_time, sliver_geometry

# 6) 内弹道
InternalBallisticsResult:
```

## 5. 正向设计与逆向设计

### 5.1 正向设计（指标 → 药型）

**输入**：F、t_b、m_p/It、I_sp、D、L/D、（可选）喷管约束。
**流程**：

1. **指标一致性校验与补全**（M1）：用 I_t=m_p·I_sp、F≈I_t/t_b 等冗余关系识别冲突，补全缺失量。
2. **推进剂/喷管选择**（M2/M3）：由工作压强与比冲需求，从数据字典选推进剂类别（数值由用户提供）。
3. **药型族选型建议**：按推力-时间形状需求与长径比给出候选族：
   - 需**近似恒定推力**（渐进-退减平衡）→ 星形/车轮形；
   - 需**递增推力**（燃面递增）→ 端面/管形（内孔）；
   - **高装载分数 + 短时间**→ 内外同时燃烧、开槽/翼柱；
   - **长径比大、多段拼接**→ 分段柱药。
4. **参数初值生成**：由需求总冲/装药量与推进剂密度反推所需**平均燃面** `Ā_b ≈ m_p/(ρ_p·r̄·t_b)`，再按族几何关系反解 θ 初值。
5. **三维药型生成**（M4）。
6. **正演计算**（M5→M6→M7→M8）。
7. **校核与迭代**（M9）：不满足则调整 θ（可调用优化器做小范围精修）。

**输出**：三维药型 + 完整性能 + 校核报告。

> **实现注记（已落地）**：第 7 步在 `api/facade.py::design_forward` 中实现为两段式——
> 解析合成给出初值后，以"推力/工作时间/总冲相对误差"为目标，在**同一正演模型**上做
> warm-start Nelder-Mead 局部精修（`_refine_synthesis`，可用 `refine=False` 关闭）。
> 示例 `06_synthesis_star`、`07_synthesis_tube` 精修后 9/9 校核通过；关闭精修可见
> 合成初值偏差（约 6/9）。精修为局部搜索，初值过远时应增大迭代或用逆向设计全局优化。

### 5.2 逆向设计（数据/要求 → 参数）—— 三条路径

| 路径 | 已知 | 目标 | 方法 |
|---|---|---|---|
| **A. 几何逆向** | 现有药型几何（CAD/STEP/点云/2D 轮廓） | 反推**参数化药型参数 θ** 与燃面特征 | 几何配准 + 参数拟合（最小二乘/配准）→ 得到 θ |
| **B. 燃面逆向** | 燃面数据 A_b(t) 或 A_b(e)（试验/文献） | 反推**药型几何 θ** | 以 A_b 为目标，优化 θ 使正演 A_b(θ) 匹配目标 |
| **C. 弹道逆向** | 推力 F(t)/总冲 It/工作时间 tb/比冲 Isp | 反推**面喉比 J(t)、药型 θ、喷管喉径** | 由 F→pc→Ab_target，再优化 θ（见 §4.3） |

**逆向统一数学形式**（正演算子记为 P）：

```
θ* = argmin_θ  Σ_t w(t)·‖ P(θ)(t) − Target(t) ‖²  + λ·R(θ)
     s.t.  θ ∈ Θ_feasible（几何/工艺/强度约束）
```

其中 P(θ) 为 M4→M5→M6→M7 组合；R(θ) 为正则项（保证解唯一、光滑、可制造）。

> **实现状态**：三条路径均已落地。
> A → `inverse.fit_outline()`（CLI `srm fit-outline`，单截面轮廓/点云）；
> A' → `inverse.analyze_existing_grain()`（CLI `srm reverse`）；
> B → `inverse.fit_burn_area()`；C → `inverse.inverse_design()`。
> 可辨识性 → `inverse.sensitivity_matrix()` / `identifiability()`（CLI `srm sensitivity`）。
> 批量研究（FR-12）→ `orchestration.study.sweep()` / `monte_carlo()`。

**关键校核点（逆向专有）**：
- **可辨识性（identifiability）**：检查目标数据是否足以唯一确定 θ；对不可辨识参数给出"冻结/多解提示"。**已实现**：整数计数标 `frozen`，工作点无响应参数标 `inactive` 并从 SVD 剔除。
- **病态性**：燃面数据对某些 θ 分量不敏感 → 用灵敏度矩阵/条件数评估并降维。**已实现**：有限差分灵敏度矩阵 + SVD 条件数 + VIF（>10 判 `confounded`）。
- **物理可行域**：反推 θ 必须满足几何不干涉、肉厚>0、余药合理、压强峰值受限。

**柱药主体计算（M8）**贯穿正/逆向：逆向得到主体几何后，需重算主体燃面、肉厚、余药与装载分数，并做工程级强度校核。

### 5.4 校核指标（Verification Metrics）

| 类别 | 指标 | 判据（工程经验，阈值可配置） |
|---|---|---|
| 弹道 | p_c(t) 峰值、时间 | ≤ 壳体/喷管许用压强 |
| 弹道 | 面喉比 J=A_b/A_t 范围 | 处于合理区间（避免压强过低/过高） |
| 弹道 | 推力 F(t) 形状 | 与需求形状偏差在容差内 |
| 性能 | 总冲 I_t、比冲 I_sp | 与需求偏差 ≤ 容差 |
| 性能 | 推力系数 C_F、膨胀比 ε | 在所选喷管设计点附近 |
| 装药 | 装载分数（体积填充率） | 合理上限提示 |
| 装药 | 余药比（sliver fraction） | ≤ 目标上限 |
| 装药 | 肉厚 e、长径比 L/D | 满足结构与几何约束 |
| 几何 | 内外通道最小间隙（工艺/通气） | ≥ 最小值 |
| 结构 | 壳体/药柱安全裕度（工程估算） | ≥ 安全系数 |
| 数值 | 守恒残差（质量/流量） | ≤ 容差 |
| 数值 | 双通道燃面一致性（解析 vs Level-Set） | 相对偏差 ≤ 容差 |
| 逆向 | 目标匹配残差、灵敏度/条件数 | ≤ 容差；条件数提示病态 |

### 5.5 核心公式（公开教科书级，供实现与校核）

- **燃速（Saint-Robert / Vieille）**：`r = a·p^n`（含温度：`r = a·p^n·exp(σ_p(T−T_ref))`，可选）。
- **喷管质量流量**：`ṁ_out = Γ·A_t·p_c/√(R·T_c)`，`Γ=√γ·(2/(γ+1))^((γ+1)/(2(γ−1)))`；工程式 `ṁ_out = p_c·A_t/c*`。
- **平衡压强**：`ρ_p·A_b·a·p^n = p·A_t/c*` ⇒ `p_c = (ρ_p·c*·a·A_b/A_t)^(1/(1−n))`。
- **推力**：`F = C_F·A_t·p_c`，`C_F = Γ·√(2γ/(γ−1)·(1−(p_e/p_c)^((γ−1)/γ))) + (p_e−p_a)/p_c·ε`（简化式）。
- **总冲/比冲**：`I_t=∫F dt`，`I_sp=I_t/(m_p·g_0)`。
- **燃面演化（Level-Set）**：`∂φ/∂t + r·|∇φ| = 0`，燃面 φ=0，燃速沿法向。
- **圆柱内孔几何燃面**：`A_b = π·D_i(t)·L`（内孔燃烧），肉厚由内外径演化求得。
- **体积装载分数**：`η_load = V_prop/V_chamber`。

> 上述公式为标准公开模型；**具体系数（a,n,σ_p,c*,γ,ρ_p）与经验阈值一律由用户/数据字典提供**。

## 8. 工程化与治理要点

1. **可复现性**：`DesignResult.provenance` 记录软件版本、依赖哈希、随机种子、模型选择与假设版本；同输入→同输出。
2. **插件注册**：推进剂/燃速/喷管/燃面算法以注册表（registry）方式插拔，新增须附验证用例。
3. **校核前置**：任何新模型进入主分支前，必须通过"解析基准 + 守恒残差 + 双通道一致性"三类校核。
4. **合规审计**：`data_registry/` 维护 SBOM 与数据来源；CI 中加入许可扫描（如 `reuse`/`licensecheck`）。
5. **教学支持**：每个模块提供 notebook 示例，展示"改一个参数→曲线如何变"，并显式打印所用公式与假设。

## 9. 明确假设清单（Assumptions）

> 凡下文未列出的细节，均为**资料不足**，本方案不给出结论。

1. 计算模型采用**公开教科书级**零维内弹道 + Saint-Robert 燃速 + 等熵喷管模型；未假设任何两相流/侵蚀燃烧的高保真模型为必备能力。
2. 推进剂配方、燃速系数、c*、γ、材料许用应力、喉部烧蚀率等**真实数值不在本方案内**，全部由用户/数据字典提供。
3. 药型以**参数化族**表示；非参数化/自由曲面药型仅通过 Level-Set 通道处理，其"可制造性"由用户判断。
4. 逆向设计的"目标数据"（A_b(t)/F(t)）被假设为**已整理、时间对齐、量纲一致**的输入；数据清洗不在核心范围。
5. 结构强度仅为**工程级简化校核**（薄壁/厚壁圆筒公式），非有限元；不构成结构定型依据。
6. 许可证建议为 Apache-2.0，最终以立项法务确认为准。
7. 开源生态项目的星标/描述为检索快照，仅用于说明现状。
8. 涉及 NASA 公开报告等文献编号，**引用前须以官方渠道核对**（本方案不臆断具体报告编号与页码）。
