# 校核与验证报告（Verification & Validation Report）

本文件记录 Srm-Open 计算内核的**校核用例、参考值、残差与结论**。所有数字均由
`pytest -m verification` 运行时打印，可一键复现：

```bash
PYTHONPATH=src python -m pytest tests/verification -m verification -q -s
```

> 参考值来自公开教科书公式、NASA CEA / Cantera（gri30 机理）与解析解。
> 所有用例均为**教学/研究级**，不构成工程定型依据。

## 1. 用例总览

| 编号 | 领域 | 校核对象 | 参考来源 | 结论 |
|---|---|---|---|---|
| V1 | 热化学 | 绝热火焰温度 T_ad | Cantera gri30（HP 平衡） | 通过（偏差 < 0.1%） |
| V2 | 喷管 | 面积比–马赫数关系、c* 恒等式 | 等熵关系解析解 | 通过（≈1e-9） |
| V3 | 几何 | 管形药柱燃面/肉厚/端口面积 | 闭式解析解 | 通过（< 0.005%） |
| V4 | 燃面 | 解析通道 vs 网格 Level-Set 通道 | 双通道互校 | 通过（最大偏差 < 8%） |
| V5 | 结构 | 轴对称 FEM vs Lamé 厚壁解 | 解析解 + 网格收敛 | 通过（< 0.4%） |
| V6 | 内弹道 | 平衡压强闭式解、质量守恒残差 | 解析解 | 通过（残差 ~1e-15） |

## 2. 详细结果（运行实测）

### V1 热化学（Gibbs 平衡求解器）

| 推进剂 | 计算 T_ad | 参考 T_ad | 相对偏差 |
|---|---|---|---|
| H₂ + 0.5 O₂ | 3077.0 K | 3077.1 K | −0.00% |
| CH₄ + 2 O₂ | 3051.7 K | 3052.2 K | −0.02% |
| CO + 0.5 O₂ | 2761.9 K | 2762.3 K | −0.01% |

内置 NASA-7 多项式数据库含 74 个组分（含 Cl 组分，用于 AP 体系），
由 `scripts/build_thermo_db.py` 生成，来源为 NASA TM-4513 / Cantera 公开数据。

### V2 喷管

- 膨胀比 ε = 12.0，γ = 1.2：由面积比关系反解出口马赫数 M_e = 3.4052，
  回代面积比恒等式得 12.0000（目标 12.0）。
- c* 恒等式 c* = √(R·T_c)/Γ 与解析式一致（相对偏差 < 1e-9）。

### V3 几何（管形药柱闭式解）

| 量 | 计算值 | 解析值 | 偏差 |
|---|---|---|---|
| 端口面积 A_p | 0.002827 m² | 0.002827 m² | −0.004% |
| 初始燃面 A_b0 | 0.094247 m² | 0.094248 m² | −0.001% |
| 肉厚 e | 0.050000 m | 0.050000 m | 0 |

### V4 燃面双通道互校（解析 vs Level-Set）

| 药型 | 最大相对偏差 | 平均相对偏差 |
|---|---|---|
| 管形 | 7.1% | 0.8% |
| 星形 | 4.0% | 0.8% |

偏差主要来自网格离散与余药端部，属于教学级网格的预期量级（配置项可加密）。

### V5 结构（FEM vs Lamé）

- 内壁环向应力：Lamé 解析 6.6364 MPa，轴对称 FEM 6.6117 MPa（偏差 −0.37%）。
- 径向应力边界条件：σ_r(a) = −p_i = −5.0 MPa，σ_r(b) = 0（精确）。
- **无体积锁死**：ν = 0.30 / 0.45 / 0.4995 三种泊松比下环向应力一致
  （6.5872 MPa，散布 4.5e-06），满足推进剂近不可压（ν→0.5）的建模需求。
  FEM 采用均值膨胀（B-bar）公式消除体积锁死。

### V6 内弹道

- 平衡压强闭式解 p_c = (ρ_p·c*·a·A_b/A_t)^(1/(1−n))：计算 2.3176 MPa
  与解析 2.3176 MPa 一致（< 1e-9）。
- 质量守恒残差：max|ṁ_gen − ṁ_out| / ṁ_out = 8.8e-16（机器精度）。

## 3. 端到端设计校核（DesignResult.verification）

正向/逆向流水线在 `DesignResult.verification.checks` 中输出以下检查项：

| 检查项 | 判据 |
|---|---|
| requirement_consistency | 指标冗余关系自洽 |
| mass_flow_balance | 平衡段 |ṁ_gen − ṁ_out|/ṁ_out < 1e-3 |
| average_thrust_vs_requirement | 与指标偏差 ≤ 5% |
| total_impulse_vs_requirement | 与指标偏差 ≤ 5% |
| burn_time_vs_requirement | 与指标偏差 ≤ 15% |
| peak_pressure_below_limit | p_c,peak ≤ 许用压强 |
| geometry_positive_dimensions | 各段尺寸为正 |
| positive_web_thickness | 肉厚 > 0 |
| grain_synthesis_mass | 合成药柱质量 vs 目标质量 |

**固定几何示例**（`examples/projects/01..05`）反映的是"给定药型的裕度评估"，
其推力/工作时间与示例中填写的名义指标并不刻意对齐，因此部分检查项会显示不通过——
这正是校核链路应当给出的提示，而非错误。

**指标驱动示例**（`examples/projects/06..07`）由指标合成药柱，并依次经过
"工作时间迭代校正 + M9 局部精修"（方案 §5.1 第 7 步）：两例的推力、工作时间与
总冲均命中指标，**9 项检查全部通过（9/9）**。

## 4. 已知局限与未决项

1. AP/HTPB 的 Gibbs 计算 T_ad（≈2062 K）低于同库 Cantera 值（≈2198 K），
   差异源于含氯组分的凝聚相与生成焓建模简化。**默认使用文献 `direct` 热化学值**，
   `ap_htpb_gibbs` 条目仅为演示，已在数据条目中注明。
2. 正向"指标驱动"合成（`design_forward`）现采用两段式：先由指标合成初值
   （体积/平均燃面/肉厚匹配 + 工作时间迭代校正），再用 **M9 局部精修**
   （warm-start Nelder-Mead，以推力/工作时间/总冲为目标，在同一正演模型上优化）
   把性能拉回指标。示例 06/07 精修后 9/9 通过。精修可在密集扫描中关闭
   （`refine=False`）以节省时间，此时推力存在少量系统偏差（0D 平衡模型下
   按设计压强定喉径），**精确命中亦可由 `inverse_design` 承担**（示例收敛 9/9）。
   精修是局部搜索：若合成初值离可行域较远，需增加 `refine_max_iter` 或改用
   `inverse_design` 的全局优化器。
3. `inverse_convergence` 检查以**达成的物理残差**（目标函数值）判定，而非优化器内部
   `success` 标志：Nelder-Mead 在单纯形收缩时会置 `success=False`，但物理目标已命中。
4. 结构校核为线弹性工程估算，未含粘弹/热循环/脱粘分析。
