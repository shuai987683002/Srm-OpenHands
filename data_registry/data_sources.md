# Data sources registry

Every numeric dataset shipped in `data/` must be traceable to a public source.
This file records what each dataset is, where it came from, and any caveats.

## Thermochemistry — `data/thermo/thermo.yaml`

- **Content**: NASA-7 (NASA 7-coefficient) thermodynamic polynomials for 74
  gas-phase and condensed species, including chlorine species used for AP-based
  propellants.
- **Origin**: gas-phase coefficients from
  B.J. McBride, S. Gordon, M.A. Reno, *Coefficients for Calculating
  Thermodynamic and Transport Properties of Individual Species*, NASA TM-4513,
  1993 — obtained via the Cantera project data files (`nasa_gas.yaml`,
  `nasa_condensed.yaml`), which document this origin.
- **Regenerated by**: `scripts/build_thermo_db.py` (reformats only; invents no
  numbers).
- **Caveat**: the file is a reformat of published coefficients. Verify against
  the official NASA/Cantera release before relying on a specific value.

## Propellants — `data/propellants/propellants.yaml`

- **Content**: *generic placeholder* entries (AP/HTPB 80/20, AP/Al/HTPB
  75/15/10, double-base) with round-number densities, burn-rate coefficients
  and thermochemistry.
- **Origin**: order-of-magnitude values consistent with open textbook
  discussion. **These are not measured or certified data.**
- **Caveat**: users must replace them with their own sourced values for any
  real analysis. The `ap_htpb_gibbs` entry is a demonstration of the built-in
  Gibbs solver and is known to under-predict T_ad (see verification report).

## Grain templates — `data/templates/templates.yaml`

- **Content**: parameterised grain families with placeholder dimensions.
- **Origin**: standard textbook grain shapes (tube, star, wagon wheel, slotted,
  finocyl, multi-perforated, spherical, conical, segmented).
- **Caveat**: dimensions are illustrative and must be scaled to a real motor.

## Reference values used only in tests

- Cantera `gri30` mechanism (adiabatic flame temperatures) — test-only, not
  shipped.
- NASA CEA values quoted in `docs/verification/` for context.

## Not included

No export-controlled, proprietary, personal or weapon-related data is present in
this repository. Contributions adding datasets must cite their public source
here.
